Runtime architecture

request → evidence → action → verification
1. Intent + risk classifierClassifies the request and flags obvious prompt-injection patterns before tools execute.
↓
2. Retrieval engineRanks a local corpus with lexical overlap. The boundary can be replaced by embeddings and a vector database.
↓
3. Tool routerSelects a typed capability rather than letting the model directly control arbitrary integrations.
↓
4. Context compilerPackages evidence, source IDs and policy constraints for grounded generation.
↓
5. Generator + verifierProduces an answer and applies evidence/abstention checks. An optional server-side Gemini adapter remains available at /api/ask.
↓
6. TelemetryRecords latency, retrieval count, confidence, risk gate and pipeline state for inspection.
